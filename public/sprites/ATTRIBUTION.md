# Map icon credits and licences

The map icon sprite (`public/sprites/og`) is built from the icons in this folder. Each icon's source is listed in
`MANIFEST.json`. This file holds the notices and credits their licences require, and is published next to the
sprite as `/sprites/ATTRIBUTION.md`.

## Public domain (CC0 1.0)

No credit is required; listed for reference.

- **Maki** by Mapbox (https://github.com/mapbox/maki): cemetery, church (`religious-christian`), fort (`castle`),
  harbor-11, hospital, library, lighthouse, park.
- **Temaki** (https://github.com/rapideditor/temaki): coral-reef, island (`island-trees-building`), museum.
